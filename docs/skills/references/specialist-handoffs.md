# Specialist handoff contracts

The holistic adviser retains final recommendation ownership.

## HM Bulls request
Include when available:
- security_or_ipo;
- decision_context;
- goal_id / purpose;
- horizon;
- maximum risk allowance;
- liquidity constraint;
- current holding and cost basis if relevant;
- current portfolio concentration if known;
- whether the user seeks long-term investment or event/listing speculation.

Expected specialist response:
- security_or_ipo;
- analysis_as_of;
- verdict;
- conviction;
- valuation_view;
- quality_view;
- risk_level;
- suggested_action;
- thesis_summary;
- top_risks;
- invalidation_triggers;
- missing_current_data;
- portfolio_context_required.

## Mutual Fund Mentor request
Include when available:
- scheme(s);
- goal_id / purpose;
- horizon;
- risk allowance;
- current SIP/holding;
- role sought: core, satellite, stability, short-term, tactical;
- existing mutual-fund portfolio for overlap analysis;
- whether switch tax/exit-load consequences matter.

Expected specialist response:
- scheme;
- analysis_as_of;
- category;
- benchmark;
- verdict;
- conviction;
- quality_view;
- risk_level;
- cost_view;
- role;
- suggested_action;
- thesis_summary;
- top_risks;
- overlap_concerns;
- tax_or_exit_load_considerations;
- invalidation_triggers;
- missing_current_data;
- holistic_context_required.

## Kanakupillai request
Include when available:
- tax_topic;
- transaction/decision being evaluated;
- relevant FY/AY if known;
- residency facts/dates;
- ownership;
- income/asset type;
- acquisition/disposal dates and cost basis when relevant;
- countries involved;
- tax already paid/withheld;
- goal/cash-flow context only if it affects planning trade-offs.

Expected specialist response:
- tax_topic;
- relevant_fy;
- relevant_ay;
- analysis_as_of;
- taxpayer_residency_status;
- key_facts_relied_on;
- domestic_tax_treatment;
- treaty_country;
- treaty_article_or_basis;
- foreign_tax_credit_or_exemption;
- estimated_tax_or_tax_range;
- compliance_actions;
- planning_options;
- key_risks;
- unresolved_facts;
- confidence;
- holistic_context_required.

## Orchestration rule
Specialist outputs are inputs, not final household decisions. Reconcile them with liquidity, debt, insurance, goals, concentration, and the user's current risk capacity before presenting the final recommendation.
